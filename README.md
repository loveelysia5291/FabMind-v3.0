## 🚀 系統快速啟動

### 方式 1：本地直接瀏覽（免任何安裝）
直接在瀏覽器雙擊開啟 `index.html` 即可完整體驗所有戰情室模擬、警報聚合與無塵室平板決策樹。

### 方式 2：使用 Python 啟動伺服器
```bash
python server.py 8080
# 瀏覽器存取: http://localhost:8080
```

## 🌐 架設在網上的方式（線上發布方案）

本專案支援 100% 免費、快速的線上部署：
1. **Netlify Drop（最快，免指令 30 秒上線）**：直接將此專案資料夾拖入 [Netlify Drop](https://app.netlify.com/drop) 即可獲得專屬 HTTPS 網址。
2. **Vercel（現代雲端發布）**：已內建 `vercel.json`，支援 GitHub 自動聯動發布。
3. **GitHub Pages**：直接推送至 GitHub 專案並於 Settings 開啟 Pages。
4. **即刻公網穿透展示**：本機啟動後，使用 `npx localtunnel --port 8080` 即可在 5 秒內產生公網連結供主管或客戶遠端檢視。

詳細圖文步驟請參閱 [`DEPLOY_GUIDE.md`](./DEPLOY_GUIDE.md)。
